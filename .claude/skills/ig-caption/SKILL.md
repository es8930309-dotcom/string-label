# /ig-caption：寫文案

## 步驟
1. 讀 `.claude/ig/voice.md`。
2. 文案結構：
   - **第一行**：會在「更多」前被看到，要能單獨成立（約 20 字內），不要跟封面字重複。
   - **內文**：短段落、一段一個重點，可用條列；給具體資訊（數字、步驟、價格、時間地點）。
   - **CTA**：一個就好，跟這篇目的一致。
   - **hashtag**：3–8 個；固定 hashtag + 主題 hashtag + 1–2 個在地 / 小眾 tag。不要堆 30 個。
3. 給 2 個版本：短版（≤ 80 字）與完整版。
4. 檢查：沒有禁用字、沒有誇大或保證療效 / 成績的說法、品名與價格與使用者提供的一致。
