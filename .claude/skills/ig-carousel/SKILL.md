# /ig-carousel：輪播貼文

## 步驟
1. 讀 `.claude/ig/voice.md`。若使用者有專用的輪播 skill（例如品牌固定版型），改用那個 skill 產圖，這裡只負責內容。
2. 預設 7–10 頁：
   - **第 1 頁**：封面，大標 ≤ 14 字 + 小副標，要有理由往右滑（「第 5 個最多人做錯」）。
   - **第 2 頁**：說明為什麼這件事重要 / 常見誤解。
   - **中間頁**：一頁一個重點，標題 ≤ 12 字，內文 ≤ 40 字。
   - **倒數第 2 頁**：總整理。
   - **最後一頁**：CTA（收藏 / 分享給球友 / 留言關鍵字）。
3. 每頁輸出：頁碼、標題、內文、畫面建議（照片 / 圖示 / 對比圖）。
4. 附一份 `/ig-caption` 格式的文案。
