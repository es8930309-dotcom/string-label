# /ig-dm：回私訊

## 步驟
1. 讀 `.claude/ig/voice.md`。
2. 判斷類型並回覆：
   - **詢價 / 想買**：回答問題 → 給價格或請對方提供需要的資訊（一次問齊，別來回問）→ 下一步（到店時間 / 下單方式）。
   - **預約**：確認日期、時間、人數 / 項目，最後重述一次讓對方確認。
   - **合作邀約**：禮貌回覆，列出需要對方提供的資訊（預算、檔期、形式），不當場答應。
   - **關鍵字索取**：謝謝 + 直接給承諾的東西（連結 / 檔案說明）+ 一個輕量的下一步。
   - **抱怨**：同 `/ig-reply` 的負評原則，給具體處理。
3. 價格、營業時間、地址只用使用者提供或 `voice.md` 裡寫的；沒有就標「需要你填」。
4. 若使用者要「範本」，產出 3–5 個常用情境的範本，可存到 `.claude/ig/dm-templates.md`。
