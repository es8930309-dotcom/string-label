# /ig-hook：Hook 打分與改寫

## 評分表（共 100 分）
| 項目 | 分數 | 看什麼 |
|---|---|---|
| 停手力 | 25 | 滑過時會不會停：反常識、衝突、具體數字、強畫面 |
| 清楚度 | 20 | 3 秒內聽得懂在講什麼，不用背景知識 |
| 切身感 | 20 | 目標受眾會覺得「在講我」 |
| 好奇缺口 | 20 | 留了一個不看完就不知道的答案 |
| 兌現度 | 15 | 影片內容真的能回答 hook，不是騙點擊 |

扣分：標題黨但內容兌現不了（兌現度直接 0）、超過 15 字的字卡、開頭先自我介紹、「大家好今天要來分享」。

## 步驟
1. 讀 `.claude/ig/voice.md` 了解受眾。
2. 對每個 hook 輸出：總分、各項分數、一句話診斷。
3. 給 5 個改寫版本，每個標註類型（反常識 / 痛點 / 數字清單 / 結果先給 / 錯誤示範 / 問句 / 對比），並打分，由高到低排序。
4. 改寫要符合使用者語氣，不用使用者禁用字。
5. 推薦一個，說明為什麼。
