# /ig-ideas：選題發想

## 步驟
1. 讀 `.claude/ig/voice.md`；若有 `.claude/ig/viral/` 的爆款紀錄，也讀最近一份，優先延伸已驗證會紅的角度。
2. 先定 3–4 個**內容支柱**（例：教學、器材知識、幕後日常、顧客故事 / 成果），沒有就提議。
3. 每個支柱給 5 個點子，每個點子包含：
   - 標題 / hook（一句）
   - 形式（Reel / 輪播 / 限動）
   - 為什麼受眾會在乎
   - 拍攝難度（低 / 中 / 高）
4. 標出 3 個「這週最值得先做」的，理由是成本低又可能有效。
5. 不要給空泛題目（「分享日常」）；每個點子都要具體到可以直接開拍。
