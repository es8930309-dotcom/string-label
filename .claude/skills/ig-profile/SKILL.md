# /ig-profile：主頁打分

## 評分表（共 100 分）
| 項目 | 分數 | 看什麼 |
|---|---|---|
| 名稱欄 | 10 | 名稱欄有沒有放關鍵字（會被搜尋到），例：「嘉友｜羽球穿線・球拍」 |
| Bio 定位 | 20 | 第一行講清楚「你幫誰做什麼」 |
| Bio 信任 | 10 | 具體證明：年資、服務人數、地點、成果 |
| CTA 與連結 | 15 | 有明確的下一步，連結能用、落地頁對應 |
| 大頭貼 | 5 | 縮小後仍認得出來 |
| 精選限動 | 15 | 有「價格 / 服務 / 評價 / 地點 / 常見問題」這類新訪客要的 |
| 置頂貼文 | 10 | 3 篇置頂是否為最能代表你、最能轉換的 |
| 九宮格 | 15 | 最近 9–12 篇主題是否一致，看得出內容支柱 |

## 步驟
1. 讀 `.claude/ig/voice.md`。
2. 看使用者給的截圖或文字。看不到的項目標「沒看到，未評分」，總分按比例換算，不要猜。
3. 輸出：總分、各項分數與一句理由、**前 3 個最該先改的**（依影響力排序）。
4. 給 3 個改寫版 Bio（每個 ≤ 150 字元）與名稱欄建議。
