# /ig-reel-script：寫 Reel 腳本

## 步驟
1. 讀 `.claude/ig/voice.md`（空白就先問領域與語氣）。
2. 確認：主題、目的（漲粉 / 互動 / 導購 / 預約）、長度（預設 20–35 秒）、誰出鏡、手上有什麼素材。缺的用合理預設並說明。
3. 先給 **3 個 hook**（不同類型），用 `/ig-hook` 的評分表各打一個總分，選最高的寫完整腳本。
4. 腳本格式：

   | 秒數 | 畫面 | 口播 | 字卡 |
   |---|---|---|---|
   | 0–3 | … | hook | 大字 ≤ 12 字 |

   - 0–3 秒一定要有畫面動作 + 字卡，靜音也看得懂。
   - 每 3–5 秒換一個畫面或節拍。
   - 一支只講一件事。
   - 結尾 CTA 只要一個（收藏 / 留言關鍵字 / 私訊 / 預約）。
5. 附上：建議封面字（≤ 10 字）、文案（交給 `/ig-caption` 的格式）、拍攝清單（要拍哪些鏡頭）。
6. 存到 `.claude/ig/scripts/YYYY-MM-DD-主題.md`。
