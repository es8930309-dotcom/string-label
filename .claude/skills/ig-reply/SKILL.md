# /ig-reply：回留言

## 步驟
1. 讀 `.claude/ig/voice.md`。
2. 讀使用者貼的留言（截圖就逐則讀出）。每則先分類：
   - 💬 一般互動 / 稱讚 → 簡短、有溫度、可反問一句延續對話
   - ❓ 問題 → 直接回答；答不出來的標「需要你確認」，不要編
   - 💰 詢價 / 想買 → 公開回一句，引導私訊，**不要**在公開留言報個資
   - 🔑 留關鍵字索取（例如「+1」「Agent」）→ 公開回「已私訊你」，並附一則私訊草稿（交給 `/ig-dm` 格式）
   - 😠 負評 / 抱怨 → 不辯解、先承認感受、給具體處理方式、引導私訊；標記給使用者親自看
   - 🚫 垃圾 / 詐騙 → 建議隱藏或刪除，不回
3. 輸出表格：留言者、原留言、分類、建議回覆。
4. 每則回覆盡量不一樣，避免整排複製貼上看起來像機器人。
5. 回覆由使用者自己貼上送出；不代替使用者登入或自動回覆。
