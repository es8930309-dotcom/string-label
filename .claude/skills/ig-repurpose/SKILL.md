# /ig-repurpose：一稿多用

## 步驟
1. 讀 `.claude/ig/voice.md` 與使用者給的原始內容。
2. 先抽出：核心觀點 1 句、3–7 個重點、最好的一句金句、原本的 CTA。
3. 依使用者要的（沒指定就全給）產出：
   - **輪播**：`/ig-carousel` 格式
   - **限動 3–5 格**：每格一句話 + 互動貼紙建議（投票 / 問答 / 測驗 / 滑桿）
   - **貼文文案**：`/ig-caption` 格式
   - **Threads 串文**：3–6 則，第一則能單獨成立
   - **新的 Reel 角度**：同主題換一個 hook，用 `/ig-reel-script` 格式
4. 各版本不要逐字重複，要針對該形式重寫。
