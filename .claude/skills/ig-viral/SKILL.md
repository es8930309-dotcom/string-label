# /ig-viral：找出你領域的爆款，再用你的聲音重寫

核心想法：**一支 Reel 有多紅，要跟那個帳號自己的平常水準比，不要跟別人比。** 10 萬粉的帳號拿到 10 萬觀看可能很普通；3 千粉的帳號拿到 3 萬觀看，那才是題材本身有力。

## 步驟

1. **讀聲音檔**：讀 `.claude/ig/voice.md`。如果還是空白範本，先跑 `/ig-voice` 的流程（或至少問清楚領域與語氣），不然重寫出來不會像使用者。
2. **收資料**（依使用者手上有什麼，選一種）：
   - 使用者給了 CSV（欄位見 `.claude/ig/data/reels-template.csv`）→ 直接用。
   - 使用者貼了一串對標帳號的 Reel 數據（文字、截圖）→ 整理成同樣欄位，存到 `.claude/ig/data/reels-YYYY-MM-DD.csv`。截圖的話逐張讀出觀看數。
   - 要看**自己帳號**：若有 Metricool 連接器，用 `getAnalyticsDataByMetrics` 抓自己的 Reels 觀看數，寫成 CSV。
   - 什麼都沒有 → 告訴使用者怎麼收：打開對標帳號的 Reels 分頁，每個帳號抄最近 8–15 支的觀看數（格子上就看得到），附連結與文案開頭。不要假造數據。
   - **不要**用爬蟲或登入使用者的 IG 帳號抓資料；這會讓帳號有風險。
3. **算倍數**：
   ```bash
   python3 .claude/skills/ig-viral/scripts/rank.py <csv> --min-x 2 --top 10
   ```
   - 平常水準 = 同帳號**其他** Reel 的觀看中位數。倍數 = 觀看 ÷ 平常水準。
   - 少於 4 支 Reel 的帳號會被略過（樣本太少），把這件事告訴使用者。
   - 只想看近期：加 `--days 60`。
4. **排名呈現**：把腳本輸出的表格給使用者（倍數最高在最前面）。
5. **拆解前 3–5 名**：每一支寫：
   - 開頭 3 秒的 hook 是什麼類型（反常識 / 痛點 / 數字清單 / 結果先給 / 好奇缺口…）
   - 題材為什麼戳中受眾
   - 結構（hook → 鋪陳 → 轉折 → CTA）
   - 可以借的「形式」，以及**不能**照抄的部分
   如果只有數字沒有內容，請使用者貼文案或口播，不要憑空猜影片內容。
6. **用使用者的聲音重寫**：挑使用者選的那支（沒選就挑最適合他領域的），產出一支完整 Reel 腳本，格式同 `/ig-reel-script`。規則：
   - 借**題材角度與結構**，不抄原句、不抄畫面、不冒充原作者。
   - 換成使用者自己的經驗、產品、案例。
   - 語氣、口頭禪、禁用字照 `voice.md`。
   - 附 3 個 hook 版本，並用 `/ig-hook` 的評分標準打分。
7. **存檔**：結果存到 `.claude/ig/viral/YYYY-MM-DD.md`（排名表 + 拆解 + 重寫腳本），方便之後回顧。

## 收尾
最後一句提醒：腳本寫好了，**拍攝與發布由使用者自己按**，不自動發文。若使用者要排程，可用 Metricool 的 `createScheduledPostForReview` 建立「待審核」排程，仍由使用者確認。
