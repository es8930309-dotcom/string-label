# /ig-voice：建立你的聲音檔

目標：填好 `.claude/ig/voice.md`，讓所有 ig-* skill 寫出來的東西像使用者本人。

## 步驟
1. 讀 `.claude/ig/voice.md` 看哪些還是「（待填）」。
2. 一次問最多 4 個問題（可用 AskUserQuestion），優先順序：
   1. 帳號與領域、一句話定位
   2. 主要受眾是誰、他們最常煩惱什麼
   3. 語氣三個形容詞、人稱、emoji 多寡
   4. 請貼 3–5 篇自己最滿意的貼文文案或 Reel 口播
3. 若使用者有其他品牌 skill（例如嘉友體育品牌 skill），可以引用裡面的語氣規則，但要先問。
4. **從範例反推**：分析使用者貼的範例，整理出句長、開頭習慣、常用詞、標點與 emoji 習慣、CTA 寫法，寫進「會用的口頭禪 / 句型」。把你推論的規則列給使用者確認。
5. 更新 `voice.md`，保留原本的段落結構。
6. 最後用新的聲音檔寫一則 50 字的示範貼文，問：「這像你嗎？哪裡不像？」依回饋再修一次。
