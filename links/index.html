社群收藏整理

使用說明
  1. 加連結：在 FB / IG / Threads / 小紅書按「分享 → 複製連結」，貼到下面的框，按「加入並自動分類」。一次貼很多個也可以。
  2. 匯入舊收藏：按「匯入檔案」，選 IG / FB / Threads 下載的收藏 JSON 檔。
  3. 分類：匯出檔大多只有「帳號名稱」沒有內文，所以會先放在「未分類」。打開下方「依帳號分類」，幫每個帳號選一次分類，同帳號的貼文就會一起歸好，之後新加的也會自動套用。
  4. 找東西：點上方的平台、分類標籤篩選，或用搜尋框。看過的按「已看」，再勾「隱藏已看」。
  5. 單筆調整：每筆的下拉選單可以改分類；「編輯」可以改標題、寫備註（備註裡的字也會拿來比對關鍵字）。
  6. 備份：資料只存在這個瀏覽器，換手機前到最下面「備份與搬家」匯出備份。

匯入檔案支援：瀏覽器匯出的書籤（.html）、IG / FB「下載你的資訊」裡的收藏 JSON、本工具的備份檔、純文字。

依帳號分類

列出收藏裡出現的帳號（未分類多的排前面）。幫帳號選一個分類，這個帳號的所有貼文都會歸到那裡，以後新加入的也會自動套用。你在單筆手動改過的不受影響。

分類與關鍵字設定

一行一個分類，格式「分類名稱: 關鍵字, 關鍵字…」。新加入的連結會用標題、備註、網址比對關鍵字，命中最多的分類勝出；都沒命中就放「未分類」。你手動改過分類的項目不會被重新分類覆蓋。

備份與搬家

資料只存在這個瀏覽器裡。換手機、換電腦或清除瀏覽資料前，先匯出備份；到新裝置用上方「匯入檔案」選備份檔即可（會合併、不會重複）。
